# 평가 기준 (10점 만점, 5개 항목)

통과: 퍼플 1·2·3 각각, 5개 항목 모두 9.5점 이상. 0.5점 단위.

| 키 | 항목 | 보는 것 |
|---|---|---|
| structure | 01 프레임워크 정교성 | 상권 성장 동인을 MECE하게 구조화하고, 분석 축 간 논리 연결이 명확한가 |
| analysis | 02 데이터 분석 정합성 | 데이터 출처·기간·단위가 일관되고, 동일 조건에서 분석 결과가 재현되는가 |
| argument | 03 주장의 설득력 | 결론이 데이터 근거와 직접 연결되고, 예상 반론에 대한 대응 논리를 갖췄는가 |
| so_what | 04 실행 시사점 | 분석 결과가 출점·투자·마케팅 등 구체적 의사결정으로 연결되는가 |
| delivery | 05 전달력 | 3분 내 결론 중심으로 전달하고, 장표당 핵심 메시지를 하나로 정리했는가 |

## 점수대

- **10**: 고칠 것이 없다. 클라이언트 임원회의에 그대로 올린다.
- **9.5**: 사소한 표현 수준만 남았다. 의사결정에 영향 없음.
- **9.0**: 근거나 논리에 작은 빈틈 1개.
- **8.0~8.5**: 결론은 맞지만 근거 일부가 약하거나 출처·단위 불일치가 있다.
- **7.0 이하**: 핵심 결론을 데이터가 받쳐 주지 못한다.

## 정합성(analysis) 감점 체크 — 모든 퍼플 공통

정합성이 이 프로젝트의 설득 핵심이므로, 아래 중 하나라도 있으면 analysis는 9.0을 넘지 않는다.

- 출처(데이터셋명 / 기준 분기 / 호출일) 없는 수치
- 비교하는 값의 분기 기준이 다름
- 단위 표기 없음, 또는 원/분기와 원/월 혼용
- 추정매출을 실측 매출처럼 표현
- 상권코드와 행정동코드 혼용
- `data_quality.md`의 결측·누락 분기가 보고서 '데이터 한계 및 보정 방법'에 반영되지 않음
- 분석 스크립트를 다시 돌렸을 때 같은 Top N이 나오지 않음

## 데이터 활용 방법 가점 관점

- 상권 → 행정동 → 자치구 단계 집계와 상대지표(자치구 평균 대비) 활용
- 8분기 추세와 이동평균으로 계절성 제거
- 점수화 가중치 공개와 민감도 분석(가중치 바꿔도 1순위 유지되는가)
- 추정매출의 한계를 다른 데이터(점포수, 유동인구)로 교차 검증
