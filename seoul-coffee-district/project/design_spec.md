# 디자인 (옐로우, 2회차)

깔끔한 에디토리얼: 손글씨·일본어 제거, Pretendard 단일 서체(제목 600, 숫자 200~300). 종이색 #F6F4F0, 잉크 #24221F, 커피 #7A5A44, 얇은 1px 선, 각진 카드(4px). 영상: 오타루 카페 실사 사진 배경(Ken Burns 확대, 어둡게), 장면당 6초 페이드, 큰 숫자 + 한 줄 설명, 성우 없음, 잔잔한 합성 피아노. 사진: "Jazz Cafe @ Otaru", MIKI Yoshihito, <a href="https://creativecommons.org/licenses/by/2.0/">CC BY 2.0</a>; "Lamps in Otaru-Station", snow rabbit, <a href="https://creativecommons.org/licenses/by-sa/2.0/">CC BY-SA 2.0</a>; via Wikimedia Commons
